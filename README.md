# CursorShake

Proyecto en fase de requisitos y diseño de una utilidad para Windows que aplica temas de cursor y permite agrandarlo al agitar el ratón. El lenguaje elegido es **C#**. La implementación todavía no ha comenzado en este repositorio.

## Documentación

- [Decisiones aceptadas](docs/Decisiones.md): acuerdos formales, valores iniciales y propuestas que siguen abiertas.
- [Requisitos](docs/Requisitos.md): comportamiento solicitado y trazabilidad R-01–R-36.
- [Experiencia de usuario](docs/ExperienciaUsuario.md): instalación, bandeja, TOML trasladable, licencias y distribución; sin CLI.
- [Equivalencias de cursores](docs/EquivalenciasCursores.md): recursos Windows y correspondencias verificadas de Bibata Ice y Nordzy blanco.
- [Pendientes de diseño](docs/PendientesDiseno.md): cuestiones por resolver antes de implementar y ejemplos de verificación.
- [Icono aceptado y procedencia](assets/branding/GENERACION.md).

Las decisiones formales se registran en el repositorio; no quedan únicamente en el chat. Una propuesta no se considera aceptada por figurar en una explicación o ejemplo. El usuario conduce el diseño y autoriza el inicio de implementación.
